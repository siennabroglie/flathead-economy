How to use this map

Select multiple categories if useful. In Single-variable mode, choose the Primary measure to control map shading. Combined index mode normalizes the selected measures to a 0–1 scale and averages them equally; it is exploratory, not a test of statistical significance. Click a block group to inspect its values.
