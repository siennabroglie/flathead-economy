How to use this map

This map provides a tool for visual comparison and analysis of publicly available data.

Map Data

Select the data to display in the map window.

Map Choropleth

Choose map configuration settings to compare selected data and perform custom analysis.

  • In Single-variable mode, choose the Primary measure to control map shading.
  • Combined index mode normalizes the selected measures to a 0–1 scale and averages them equally.

Click a block group to inspect its values. Hold Shift or Command to select multiple block groups at once. Click outside the block groups to refresh the selection.

Data Summary

View data totals. The default settings show totals for Flathead County. Select a block group in the map window to view its totals. Use the toggle in the upper-right corner of this window to compare a selected block group's totals with county-wide data.

Sources: U.S. Census Bureau ACS and LEHD Origin-Destination Employment Statistics (LODES).
